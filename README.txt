Верёвка Кирилла. Проект для Android Studio.

1. Установите Android Studio (developer.android.com/studio).
2. File -> Open, выберите эту папку (VerevkaKirilla). Дождитесь окончания Gradle Sync
   (нужен интернет, студия сама скачает всё нужное).
3. Build -> Build Bundle(s) / APK(s) -> Build APK(s).
4. Когда появится сообщение, нажмите "locate". Файл: app/build/outputs/apk/debug/app-debug.apk
5. Скопируйте app-debug.apk на телефон и установите (разрешите установку из неизвестных источников).

Страница приложения лежит в app/src/main/assets/index.html, иконки в app/src/main/res/mipmap-*.
